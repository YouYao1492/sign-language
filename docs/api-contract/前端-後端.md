# 前端 ↔ 後端

Base URL：

```text
/api
```

---

## 1. Login

### POST `/api/login`

Request：

```json
{
  "email": "user@example.com",
  "password": "password"
}
```

Response：

```json
{
  "success": true,
  "data": {
    "user_id": "user-001",
    "email": "user@example.com",
    "role": "deaf",
    "token": "token-example"
  },
  "error": null
}
```

Role：

```text
deaf
staff
```

---

## 2. Create Session

### POST `/api/sessions`

Request：

```json
{
  "scenario_id": "bank",
  "language": "zh-TW"
}
```

Response：

```json
{
  "success": true,
  "data": {
    "session_id": "session-001",
    "scenario_id": "bank",
    "language": "zh-TW",
    "status": "active"
  },
  "error": null
}
```

---

## 3. Sign Video Recognition

### POST `/api/recognize`

Content-Type：

```http
multipart/form-data
```

Form Data：

```text
video        = <video file>
session_id   = session-001
scenario_id  = medical
language     = zh-TW
```

Response：

```json
{
  "success": true,
  "data": {
    "text": "我要辦信用卡"
  },
  "error": null
}
```

後端收到AI結果後，前端拿到 response.data.text

# MVP Error Codes

| ---- | ----------------------- |
| 400  | `INVALID_REQUEST`     |

| 401  | `INVALID_CREDENTIALS` |
| 403  | `FORBIDDEN`           |
| 404  | `SESSION_NOT_FOUND`   |
| 404  | `SCENARIO_NOT_FOUND`  |
| 409  | `SESSION_COMPLETED`   |
| 500  | `SERVER_ERROR`        |
