# A. 前端 Checklist

## JavaScript 模組

* `js/main.js`：應用程式入口與功能初始化
* `js/api/apiClient.js`：共用 HTTP、JSON、錯誤與授權標頭處理
* `js/api/authApi.js`：登入與註冊 API
* `js/features/auth.js`：登入、註冊與使用者狀態
* `js/features/sessions.js`：Session 建立、完成與目前 Session 管理
* `js/features/camera.js`：攝影機權限與預覽
* `js/features/recognition.js`：影片上傳與手語辨識 API
* `js/features/chat.js`：聊天訊息與文字輸入
* `js/features/voice.js`：按住說話與語音辨識
* `js/features/avatar.js`：虛擬人手語動畫

Session 與影片辨識可透過入口提供的 `window.signBridge` 呼叫：

```js
await window.signBridge.sessions.create("medical");
const text = await window.signBridge.recognizeVideo(videoBlob);
await window.signBridge.sessions.complete();
```
