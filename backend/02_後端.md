# B. 後端 Checklist

## Server

* [X] backend 檔案建制
* [ ] Node.js / Express Server 可以正常啟動
* [ ] `.env` 設定完成
* [ ] MongoDB 可以正常連線
* [ ] API Base Path 統一為 `/api`

## Login

* [ ] 實作 `POST /api/login`
* [ ] 接收 `email`
* [ ] 接收 `password`
* [ ] 驗證帳號
* [ ] 驗證密碼
* [ ] 登入成功產生 Token
* [ ] Response 回傳 `user_id`
* [ ] Response 回傳 `role`
* [ ] Response 回傳 `token`
* [ ] 登入失敗回傳 `401`

## Authentication

* [ ] 實作 JWT 驗證 Middleware
* [ ] 可以解析 `Authorization: Bearer <token>`
* [ ] Token 無效回傳 `401`
* [ ] Token 過期回傳 `401`
* [ ] 可以從 Token 取得 `user_id`
* [ ] 可以從 Token 取得 `role`
* [ ] 不依賴 Frontend 傳送 `user_id`

## Session

* [ ] 實作 `POST /api/sessions`
* [ ] API 必須驗證 Token
* [ ] 從 Token 取得 `user_id`
* [ ] 接收 `scenario_id`
* [ ] 接收 `language`
* [ ] 建立 Session
* [ ] 產生 `session_id`
* [ ] Session 預設為 `active`
* [ ] 回傳 `session_id`
* [ ] 回傳 `scenario_id`
* [ ] 回傳 `language`
* [ ] 回傳 `status`

## Sign Recognition

* [ ] 實作 `POST /api/recognize`
* [ ] API 必須驗證 Token
* [ ] 接收 Video
* [ ] 接收 `session_id`
* [ ] 接收 `scenario_id`
* [ ] 接收 `language`
* [ ] 驗證 Session 是否存在
* [ ] 驗證 Session 是否屬於目前 User
* [ ] 驗證 Video 是否存在
* [ ] 將 Video 傳送給 AI
* [ ] 接收 AI 回傳的 `text`
* [ ] 將辨識結果建立成 Message
* [ ] 回傳辨識結果給 Frontend
